Grid Areas

Grid areas let you name sections of a layout and place items into those named areas.

HEADER
SIDEBAR
MAIN CONTENT
FOOTER

The CSS layout is defined using:

grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";

The header and footer span both columns. On smaller screens, the media query changes the layout into a single column.
