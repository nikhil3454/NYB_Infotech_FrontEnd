5. Important Animation Properties

/* 1. Animation name */
animation-name: move;

/* 2. One iteration's duration */
animation-duration: 2s;

/* 3. Speed pattern */
animation-timing-function: ease-in-out;

/* 4. Delay before starting */
animation-delay: 0.5s;

/* 5. Number of iterations */
animation-iteration-count: 3;
animation-iteration-count: infinite;

/* 6. Direction */
animation-direction: normal;
animation-direction: reverse;
animation-direction: alternate;
animation-direction: alternate-reverse;

/* 7. Styles before and after animation */
animation-fill-mode: none;
animation-fill-mode: forwards;
animation-fill-mode: backwards;
animation-fill-mode: both;

/* 8. Pause or resume */
animation-play-state: paused;
animation-play-state: running;

/* Shorthand:
   name duration timing-function delay
   iteration-count direction fill-mode play-state
*/
animation: move 2s ease-in 0.5s infinite alternate;

/* Multiple animations */
animation:
    spin 4s linear infinite,
    fade 2s ease-in-out infinite alternate;

6. Understanding @keyframes

@keyframes example {
    0% {
        transform: translateX(0);
        background-color: blue;
    }

    25% {
        transform: translateX(25px);
        background-color: orange;
    }

    50% {
        transform: translateX(0);
        background-color: red;
    }

    75% {
        transform: translateX(-25px);
        background-color: purple;
    }

    100% {
        transform: translateX(0);
        background-color: blue;
    }
}

.box {
    animation: example 4s ease-in-out infinite;
}

The browser moves between the specified keyframes over the animation duration. Intermediate values are calculated when the browser can interpolate the animated properties.

7. Accessibility and Performance

Respect reduced-motion preferences and avoid excessive continuous animations. 

@media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}

For many movement effects, use transform and opacity instead of repeatedly changing layout properties such as top, left, width, and height. Always test actual browser performance.
