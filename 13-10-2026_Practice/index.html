4. Float and Clear

float: left

Float Left

This paragraph wraps around the floated box. The float is positioned on the left, allowing the text to occupy the space to its right. As the text continues, it can flow underneath the floated element when there is no longer enough horizontal space beside it.

float: right

Float Right

This paragraph wraps around the floated box on its left side. Float can be useful for placing illustrations beside text in articles and other text-heavy layouts.

clear: both

Float Left
Float Right

This text is between the floated elements and may wrap around them.

This footer uses clear: both, so it moves below the left and right floats.

display: flow-root

The float containers use display: flow-root so their height includes the floated children.
